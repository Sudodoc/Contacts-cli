# Contacts-cli

Данная программа является консольным списком контактов.

Доступный функционал :
    
    1. Добавить контакт. 
    2. Вывести список всех контактов.
    3. Найти контакты по заданной строке.
    4. Изменить контакт.
    5. Удалить контакт.

Настройки задаются в файле settings.json

    **first_run_ini**
    Определяет первый запуск программы. Устанавливается значение False после первого запуска. Понадобится
    если в дальнейшем добавить функционал сброса программы.
    
    **language**
    Язык интерфейса. По умолчанию 'en', но можно изменить на русский при первом запуске.

    **count**
    Счетчик. Отображает общее кол-во когда бы то нибыло созданных контактов. Целосообразно в случае дальнейшего
    добавления функционала архивации контактов и восстановления после удаления.
